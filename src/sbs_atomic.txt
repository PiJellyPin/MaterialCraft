# The built-in node types of the .sbs package format: the atomic compositing filters, the nodes of function graphs
# and of FX-map graphs. Identifiers, value types, input names and creation defaults follow the format's reference,
# Adobe's Substance Automation Toolkit documentation (Apache-2.0, github.com/AdobeDocs/substance-automation-toolkit);
# the labels, groupings and slider ranges are MaterialCraft's own. See INDEPENDENT_IMPLEMENTATION.md.
#
#   @<identifier> <family> <label>         family: texture, function or pattern
#   > <output> [<output> ...]               outputs (function nodes: the result type)
#   < <input> <kind> [many]                 inputs: c colour or grey, g grey, a value type for function nodes;
#                                           `many` = repeatable (input, input:1, input:2 ...)
#   - <param> <type> <default...> [~ <min> <max>] [= <choice>|<choice>|...] [rel]
#        types: f1-f4 float, i1-i4 integer, b boolean, s text, path, fv (float4 in colour, float1 in grey mode)
#        choices are listed in code order (0, 1, 2 ...); `rel` = may be relative to the parent or the input
#
# The settings every image filter has (output size, format, pixel size and ratio, tiling, random seed) are listed
# once under @$base.

@$base texture Base settings
- outputsize i2 0 0 ~ -12 12 rel
- format i1 0 = 8 bits|16 bits|16 bits float|32 bits float rel
- pixelsize f2 1 1 rel
- pixelratio i1 0 = Square|Stretch rel
- tiling i1 3 = No tiling|Horizontal|Vertical|Horizontal and vertical rel
- randomseed i1 0 ~ 0 10000 rel
